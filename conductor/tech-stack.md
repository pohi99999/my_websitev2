# Tech Stack: Weboldal + AI KKV-knak

## Core Technologies
- **Next.js (App Router):** Modern React-alapú keretrendszer az optimális renderelésért és útvonalkezelésért.
- **TypeScript / JavaScript:** A típusbiztonság és a robusztus kódfejlesztés érdekében.
- **Tailwind CSS:** Utility-first CSS keretrendszer a gyors és reszponzív stíluskezeléshez.

## UI & Animation
- **React:** A komponens-alapú felépítésért.
- **Lucide React:** Modern, testreszabható ikonkészlet.
- **Framer Motion:** Smooth, deklaratív animációk és interakciók.
- **GSAP (GreenSock):** Komplexebb, nagy teljesítményű animációk kezeléséhez (ha szükséges).

## Quality Assurance & DevOps
- **Playwright:** E2E tesztelés, böngésző-automatizálás és vizuális ellenőrzés.
- **Git (GitHub):** Verziókezelés és forráskód-tárolás.
- **Vercel / Netlify:** CI/CD alapú deployment (a main ágból).
- **ESLint / Prettier:** Kódminőség és egységes formázás biztosítása.

## Additional Features
- **Upstash (Redis/Ratelimit):** Szerveroldali korlátozás és gyorsítótárazás.
- **Vercel Analytics:** Látogatói statisztikák nyomon követése.
